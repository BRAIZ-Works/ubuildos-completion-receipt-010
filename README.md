# Quote Follow-Up Tracker — Day 09 / 30

A public-safe static proof of **commercial follow-through**: keep synthetic quote records visible by sent date, value band, next follow-up, owner, response state, and deterministic due state.

## Inspect it
1. Open the GitHub Pages site for this repository.
2. Keep the explicit **as-of date** at `2026-09-30` to reproduce the included proof state.
3. Filter/search/sort, add or edit a local demo record, then export the current visible view to CSV or JSON.

## What it proves
- deterministic `OVERDUE / DUE_TODAY / UPCOMING / CLOSED / REVIEW` logic;
- closed quote states do not become due through date logic;
- invalid material data fails closed to visible `REVIEW` with a reason;
- visible-state CSV/JSON export;
- keyboard-operable public demo with no backend and no external sales action.

## What it does not do
No CRM integration, email/SMS sending, payment/invoice action, customer PII, win-probability scoring, revenue forecasting, autonomous outreach, hidden ranking, or business-outcome guarantee.
